# Prints a capturar

Atalho do Windows para capturar uma área da tela: `Win + Shift + S`. Salvar nesta pasta com estes nomes:

| Arquivo | O que capturar |
|---|---|
| `01-actions-lista.png` | Aba **Actions** do GitHub com o run "Testes" verde |
| `02-actions-detalhe.png` | Run aberto mostrando os passos (Baixar o código → Rodar os testes → Publicar relatórios) |
| `03-junit-terminal.png` | Terminal com `Tests run: 6, Failures: 0` e `BUILD SUCCESS` |
| `04-junit-vscode.png` | (opcional) Aba Testing do VS Code com os 6 testes verdes |
| `05-api-rodando.png` | Terminal com a API iniciada na porta 7070 |
| `06-postman-runner.png` | Collection Runner do Postman com os 18 testes passando |
| `07-postman-saida-11.png` | Requisição "Saída de 11" aberta: corpo enviado, resposta 400 e aba Test Results |

Esses prints também servem de **plano B** se a demonstração ao vivo falhar no dia.
